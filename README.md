# AI Student Performance Prediction

## Problem Statement

Educational institutions often struggle to identify students who may require additional academic support before final examinations.

This project aims to build a Machine Learning system that predicts a student's final academic performance based on various academic, behavioral, and socio-economic factors.

The final system will help students understand which factors most influence their performance and provide personalized suggestions for improvement.

---

## Objectives

- Predict student performance
- Compare multiple ML algorithms
- Explain predictions using Explainable AI
- Deploy as a web application
- Learn the complete Machine Learning workflow
